# Supplementary tables and figure code

Open [Results.xlsx](data/Results.xlsx) to browse Supplementary Tables S1–S33. The first worksheet lists each table and its location. Lettered components are grouped under their main table number.

[Figure_data.xlsx](data/Figure_data.xlsx) contains plotting inputs. The `code/` directory contains the supplied figure scripts, and `requirements.txt` lists their Python dependencies.

```sh
python code/figure2.py --output figures
python code/table_s2.py
```
